# PSVMS: лицензирование и генератор

## Что добавлено

- Проверка лицензии по цифровой подписи Ed25519 (OpenSSL).
- Привязка файла `.lic` к ID компьютера, который показывает вкладка **Настройки → Лицензия**.
- Готовые сроки: 30, 60, 90 и 120 дней.
- Произвольный срок: дни, часы и минуты.
- Альтернативный режим: точная дата и время окончания.
- Время для режима длительности отсчитывается с момента импорта лицензии в PSVMS.
- Без действующей лицензии действует демо-лимит до 10 камер.

## Важное о ключах

`psvms.cpp` содержит только открытый ключ. Приватный ключ `psvms_license_private.pem` используется генератором для подписи и **не должен попадать в GitHub, публичные архивы, переписку или к клиентам**. Потеря приватного ключа означает, что выпускать новые лицензии с текущим открытым ключом будет невозможно. Сделайте две защищённые резервные копии.

Файл приватного ключа поставляется отдельно от исходного ZIP. Создайте в корне проекта папку `keys` и положите туда `psvms_license_private.pem` либо выберите PEM через кнопку «Обзор…». Перед публикацией проекта проверьте, что каталог `keys` и файл `*.pem` не добавлены в репозиторий. Рекомендуется добавить их в `.gitignore`.

## Сборка PSVMS

1. Скопируйте `psvms.cpp`, `CMakeLists.txt` и `.github/workflows/build-windows.yml` в репозиторий.
2. Workflow устанавливает FFmpeg и OpenSSL через vcpkg, собирает PSVMS и публикует `PSVMS-windows`.
3. Важно: эта версия исходника требует OpenSSL Crypto при сборке. Сборка Windows/Qt в этой среде не выполнялась; проверьте GitHub Actions перед распространением.

## Сборка генератора лицензий (Windows)

Требуются Qt 6.8.1 MSVC 2022 64-bit, Visual Studio 2022 C++ и vcpkg.

1. Распакуйте `license_generator`.
2. Откройте `build_windows.bat` и при необходимости исправьте `QT_DIR` и `VCPKG_ROOT`.
3. Запустите `build_windows.bat`.
4. Исполняемый файл появится в `license_generator/build/Release/PSVMSLicenseGenerator.exe`.
5. В генераторе укажите клиента, ID компьютера, тип и срок, приватный PEM-ключ и путь сохранения.
6. Передайте клиенту только созданный файл `.lic`.

## Выпуск лицензии

1. На компьютере клиента открыть PSVMS → Настройки → Лицензия.
2. Нажать «Скопировать ID компьютера» и отправить ID вам.
3. В генераторе вставить ID и выбрать 30/60/90/120 дней, произвольную длительность или точную дату/время.
4. Создать `.lic` и передать его клиенту.
5. Клиент загружает `.lic` через «Активировать файл лицензии».

## Ограничения офлайн-лицензирования

Подпись защищает содержимое файла от подделки, а привязка ограничивает его использование указанным компьютером. Полностью защитить офлайн-программу от опытного вмешательства в локальные настройки или системные часы невозможно. PSVMS запоминает последнее проверенное время и выявляет обычный перевод часов назад, но для более сильной защиты потребуется серверная активация/периодическая онлайн-проверка.
